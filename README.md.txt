# Chatbot FURIA - Bot Interativo para Fãs

Este projeto é um chatbot criado com a plataforma Landbot, voltado para atender fãs da organização FURIA. Através de uma interface interativa, os usuários podem obter informações sobre line-ups dos times, horários de jogos, redes sociais e muito mais.

## Link do Bot Ativo

Você pode testar o chatbot em funcionamento pelo link abaixo:

[Chatbot FURIA](https://landbot.online/v3/H-2903711-H9VZMZRV3193LWUK/index.html)

## Funcionalidades

- Consulta rápida sobre os times da FURIA (CS2, Valorant, etc.)
- Informações atualizadas sobre próximos jogos
- Acesso às redes sociais e à loja oficial da FURIA
- Navegação simples com opção de retorno ao menu principal

## Como Utilizar

Este bot foi desenvolvido diretamente na plataforma Landbot. Todo o fluxo foi criado manualmente através da interface de blocos visuais, sem necessidade de importação de arquivos externos ou customização com CSS.

### Para criar um bot semelhante:
1. Acesse [landbot.io](https://landbot.io) e faça login
2. Crie um novo chatbot do tipo **Web**
3. Reproduza o fluxo utilizando os blocos de diálogo, condições e botões
4. Publique e compartilhe o link com seus usuários
